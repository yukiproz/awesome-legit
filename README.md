# ❄ awesome-legit

**Hyped but legit.** Repos with loud numbers that survived verification: real activity, real usage signals, real maintainers. Star counts are shown but never trusted blindly — every entry below was checked live (October 2026).

Dropped along the way: repos stale 9+ months and sub-500-star curiosities. Hype without substance doesn't make this list.
